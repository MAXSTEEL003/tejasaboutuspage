# Tejas Canvassing – Premium Web Experience

An interactive 3D web experience showcasing Tejas Canvassing's heritage, aged rice varieties (Keshar Kali, HMT, Sona Masoori, KNM, 1121 Basmati), milling process in Karnal, and nationwide distribution network.

## Features & Highlights

- **Interactive 3D Rice Packaging**: Photorealistic Three.js scene featuring authentic 30kg Keshar Kali packaging with dynamic lighting and camera interactions.
- **Dynamic India Map Network**: High-performance vector & 3D canvas mapping out nationwide sourcing and distribution hubs.
- **Cinematic Storytelling & Smooth Scroll**: Lenis-powered smooth scrolling with chapter-based parallax journeys and grain visuals.
- **Performance Optimized**:
  - Code-split Three.js bundles & lazy-loaded 3D modules.
  - Pre-rendered film grain layers and non-blocking font swapping.
  - Optimized WebP assets reducing payload size.
  - Strict TypeScript and Tailwind CSS v4 styling.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **3D Engine**: Three.js
- **Styling**: Tailwind CSS v4
- **Smooth Scroll**: Lenis
